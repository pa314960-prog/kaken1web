# Hand Gesture Effects

Webカメラの映像から手のジェスチャーを認識し、ジェスチャーに応じて画面エフェクトを切り替えるブラウザアプリです。ビルド不要の静的ファイル（HTML / CSS / JS）のみで構成されており、CDN から [MediaPipe Hand Landmarker](https://developers.google.com/mediapipe) と [Three.js](https://threejs.org/) を読み込んで動作します。

## 公開URL（GitHub Pages）

https://pa314960-prog.github.io/kaken1web/

ブラウザで上記URLを開き、「カメラを開始」ボタンをクリックしてカメラ使用を許可すれば利用できます（インストール不要）。

## 必要なもの

- Google Chrome または Microsoft Edge（最新版を推奨）
- インターネット接続（初回読み込み時のみ）
- Git（プロジェクトの取得・更新に使用。無い場合は下記手順でインストールします）
- Python（ローカルサーバーの起動に使用。無い場合は下記手順でインストールします）

## 一番簡単な方法: 自動セットアップスクリプト

他のPCで一からセットアップするのが面倒な場合は、コマンドを1つ実行するだけで「Git/Pythonが無ければインストール → プロジェクトを取得 → サーバー起動 → ブラウザを開く」まで自動でやってくれるスクリプトを用意しました。**何をするスクリプトかは `scripts/setup-windows.ps1` / `scripts/setup-mac.sh` の中身で確認できます**（GitHubからダウンロードしてそのまま実行するので、心配な場合は先に中身を見てから実行してください）。

### Windows

1. スタートメニューで「PowerShell」を検索して開く（管理者権限は不要です）
2. 次のコマンドをコピーして貼り付け、Enter
   ```
   irm https://raw.githubusercontent.com/pa314960-prog/kaken1web/claude/hand-gesture-effects-glik5u/scripts/setup-windows.ps1 | iex
   ```
3. Git/Pythonが入っていない場合は自動でインストールが始まります（少し時間がかかります）。インストール直後は「もう一度実行してください」と表示されることがあるので、その場合はもう一度PowerShellを開き直して同じコマンドを実行してください
4. 完了すると自動でブラウザが開きます。「カメラを開始」ボタンをクリックし、カメラ許可のダイアログで「許可」を選べば準備完了です

初回にGitやPythonをインストールする都合上、完全に無人では終わらず「もう一度実行」が必要になる場合がある点だけご了承ください。それ以外はこのコマンド1つで完結します。

### Mac

1. `Command + スペース` → 「ターミナル」と入力してEnter
2. 次のコマンドをコピーして貼り付け、Enter
   ```
   curl -fsSL https://raw.githubusercontent.com/pa314960-prog/kaken1web/claude/hand-gesture-effects-glik5u/scripts/setup-mac.sh | bash
   ```
3. Gitが入っていない場合、「コマンドラインデベロッパツール」のインストールを促すポップアップが出るので「インストール」をクリックし、完了したら同じコマンドをもう一度実行してください
4. 完了すると自動でブラウザが開きます。「カメラを開始」ボタンをクリックし、カメラ許可のダイアログで「許可」を選べば準備完了です

**2回目以降も同じコマンドを実行するだけで、最新版に更新してから起動してくれます。**

自動スクリプトを使わず、内容を理解しながら一つずつ手動で進めたい場合は、以下の手順を参照してください。

## 手順1: Gitをインストールする（Windows）

すでに `git --version` でバージョンが表示される場合はこの手順は不要です。次の「手順2」に進んでください。

1. ブラウザで https://git-scm.com/downloads/win を開く
2. 「Click here to download」（64-bit Git for Windows Setup）をクリックしてインストーラーをダウンロード
3. ダウンロードした `.exe` ファイルをダブルクリックして実行する
4. インストーラーの各画面はすべて**デフォルト設定のまま「Next」を押して進めればOK**です（設定変更は不要）
5. 最後に「Install」→「Finish」でインストール完了
6. PowerShellを開いている場合は一度閉じて、新しく開き直す
7. 新しいPowerShellで次を入力してEnter
   ```
   git --version
   ```
   `git version 2.x.x` のように表示されればインストール成功です

### Macの場合
Macは通常、初めて `git` コマンドを実行したタイミングで「コマンドラインデベロッパツールがインストールされていません」というポップアップが自動的に出ます。その場合は「インストール」をクリックし、完了するまで待ってください（数分かかります）。ポップアップが出ない場合はすでにGitが使える状態です。

## 手順2: プロジェクトを取得する（git clone）

### Windows

1. スタートメニューで「PowerShell」を検索して開く
2. フォルダを置きたい場所に移動する（例: デスクトップ）
   ```
   cd $HOME\Desktop
   ```
   - `cd : パス 'C:\WINDOWS\system32\Desktop' が存在しないため検出できません。` のようなエラーが出た場合、PowerShellが `C:\WINDOWS\system32` を起点に開いています（管理者権限で開いた場合など）。相対パスの `Desktop` ではなく上記の `$HOME\Desktop` を使ってください。
   - それでも失敗する場合は `whoami` でユーザー名を確認し（`PC名\ユーザー名` の形式で表示される）、`cd C:\Users\ユーザー名\Desktop` のように絶対パスで指定してください。
3. 次のコマンドでクローンする（フォルダをまるごとダウンロードする）
   ```
   git clone -b claude/hand-gesture-effects-glik5u https://github.com/pa314960-prog/kaken1web.git
   ```
4. 完了すると `Desktop` の中に `kaken1web` フォルダが作成されます

### Mac

1. `Command + スペース` でSpotlight検索を開き、「ターミナル」と入力してEnter
2. フォルダを置きたい場所に移動する（例: デスクトップ）
   ```
   cd ~/Desktop
   ```
3. 次のコマンドでクローンする
   ```
   git clone -b claude/hand-gesture-effects-glik5u https://github.com/pa314960-prog/kaken1web.git
   ```
4. 完了すると `Desktop` の中に `kaken1web` フォルダが作成されます

## 手順3: ローカルサーバーを起動して開く

### Windows

1. クローンした `kaken1web` フォルダに移動する
   ```
   cd kaken1web
   ```
2. Pythonがインストールされているか確認する
   ```
   python --version
   ```
   - `Python 3.x.x` のように表示されればOK → 次へ進む
   - 「見つかりません」等のエラーが出た場合は以下の手順でインストールする
     1. https://www.python.org/downloads/ を開く
     2. 「Download Python」ボタンでインストーラーをダウンロード
     3. インストーラーを実行する際、**「Add python.exe to PATH」に必ずチェック**を入れる
     4. インストール完了後、PowerShellを一度閉じて開き直す
     5. `python --version` をもう一度実行し、`Python 3.x.x` と表示されることを確認する
3. ローカルサーバーを起動する
   ```
   python -m http.server 8000
   ```
   何も表示されず固まったように見えますが、これは起動できている状態です。**このウィンドウは閉じずにそのままにしておきます。**
   - ⚠️ **このウィンドウはサーバーが動き続けている間、他のコマンドを打てなくなります。** 別のコマンド（`git pull` など）を実行したい場合は、このウィンドウとは別に新しいPowerShellウィンドウを開いて操作するか、一度 `Ctrl + C` を押してサーバーを停止してから操作してください。
4. Chrome または Edge を開き、アドレスバーに次を入力してEnter
   ```
   http://localhost:8000
   ```
   「Hand Gesture Effects」のページが表示されます
5. 画面中央の **「カメラを開始」ボタン**をクリック
6. ブラウザ上部に「カメラの使用を許可しますか？」という確認が出るので **「許可」をクリック**
7. カメラに手を映し、ジェスチャーをしてエフェクトが出るか確認する

**終了するとき**: PowerShellのウィンドウに戻り `Ctrl + C` を押すとサーバーが止まります。

### Mac

1. クローンした `kaken1web` フォルダに移動する
   ```
   cd kaken1web
   ```
2. Pythonがあるか確認する
   ```
   python3 --version
   ```
   - `Python 3.x.x` と表示されればOK → 次へ進む（Macは標準でPython3が入っていることが多い）
   - コマンドが見つからないエラーが出た場合は https://www.python.org/downloads/ からインストールする
3. ローカルサーバーを起動する
   ```
   python3 -m http.server 8000
   ```
   固まったように見えますが起動できています。**このターミナルは閉じずにそのままにします。**
   - ⚠️ このターミナルはサーバーが動き続けている間、他のコマンドを打てなくなります。別のコマンドを実行したい場合は新しいターミナルウィンドウを開くか、`Control + C` で一度停止してください。
4. Chrome を開き、アドレスバーに次を入力してEnter
   ```
   http://localhost:8000
   ```
5. 「カメラを開始」ボタンをクリック
6. 確認ダイアログで「許可」をクリック
7. **システム設定側でもブラウザのカメラアクセスが許可されているか**を確認する
   - `システム設定` → `プライバシーとセキュリティ` → `カメラ` → 使用しているブラウザ（Chrome等）にチェックが入っているか確認
8. カメラに手を映してエフェクトが出るか確認する

**終了するとき**: ターミナルに戻り `Control + C` でサーバーを停止します。

## アップデート（最新版の取得方法）

新しい変更を取り込みたいときは、フォルダを取り直す必要はありません。次の手順で更新できます。

1. サーバーを起動しているPowerShell/ターミナルがあれば、そのウィンドウをクリックして `Ctrl + C`（Macは `Control + C`）で一度停止する
   - もしくは、サーバーはそのままにして**新しいPowerShell/ターミナルウィンドウをもう1つ開く**
2. `kaken1web` フォルダに移動する
   ```
   cd C:\Users\ユーザー名\Desktop\kaken1web
   ```
   （Macの場合は `cd ~/Desktop/kaken1web`）
3. 最新版を取得する
   ```
   git pull origin claude/hand-gesture-effects-glik5u
   ```
4. サーバーを（再）起動する
   ```
   python -m http.server 8000
   ```
   （Macは `python3 -m http.server 8000`）
5. ブラウザで `http://localhost:8000` を再読み込みする

## うまく動かない場合のチェックリスト

| 症状 | 原因の可能性 | 対処 |
|---|---|---|
| `cd Desktop` で「パス 'C:\WINDOWS\system32\Desktop' が存在しません」と出る | PowerShellが `system32` を起点に開いている（管理者権限で開いた等） | `cd $HOME\Desktop` を使う。ダメなら `whoami` でユーザー名を確認し `cd C:\Users\ユーザー名\Desktop` |
| コマンドを打っても何も反応しない・打てない | そのウィンドウで `python -m http.server` が実行中で、サーバーが動作し続けている状態 | 新しいPowerShell/ターミナルウィンドウを別に開いて操作する。もしくは `Ctrl + C`（Macは `Control + C`）でサーバーを一度停止してから操作する |
| ページが真っ白/読み込まれない | サーバーが起動していない | サーバー起動のコマンドを再実行し、エラーが出ていないか確認する |
| 「カメラを開始」を押しても反応しない | ブラウザの権限がブロック済み | ブラウザのアドレスバー左のカギ/カメラアイコンをクリックし、カメラ許可を「許可」に変更してページを再読み込みする |
| 手を映してもジェスチャーが反応しない | 照明が暗い、または手が画面端で切れている | 明るい場所で、手首から指先まで画面内に入るようにする |
| 何も表示されずエラーが出る | インターネット接続がない | 初回はCDN（外部サーバー）からライブラリを読み込むため、ネット接続が必要 |
| `git` コマンドが見つからないと言われる | Gitがインストールされていない | 「手順1: Gitをインストールする」を実施する |

## ジェスチャーとエフェクト対応表

| # | ジェスチャー | 条件 | エフェクト |
|---|---|---|---|
| 1 | ハート | 両手の親指同士・人差し指同士を近づけてハート形を作る | 手の間から赤い3Dハートが出現し、ゆっくり上昇しながら広がる |
| 2 | ピース（片手） | 片手でピースサイン | 画面下からカラフルな風船が浮かび上がる |
| 3 | ピース（両手） | 両手でピースサイン | 画面上から紙吹雪が降る |
| 4 | グッド（片手） | 片手で親指を立てる | 「いいね」の吹き出しがふわっと浮かび上がる |
| 5 | グッド（両手） | 両手で親指を立てる | 背景が暗くなり、花火が次々に打ち上がる |
| 6 | バッド（片手） | 片手で親指を下に向ける | 「バッド」の吹き出しが浮かび上がる |
| 7 | バッド（両手） | 両手で親指を下に向ける | 背景が暗くなり、雲と大雨が降る |
| 8 | メロイックサイン | 人差し指と小指を立てる（中指・薬指は曲げる） | 背景にカラフルなレーザービームが広がる |

ジェスチャーは数フレーム連続で検出できた時点で確定し（誤検出防止のためのデバウンス）、手をフレームから外すと即座にエフェクトが止まります。

## 別環境で動かす際に変更が必要になりうる点

基本的に**このフォルダをコピーするだけ**で動きます。以下は稀に調整が必要になるケースです。

- **社内プロキシ等でCDNがブロックされる場合**: `src/handTracking.js` と `src/effects/heart.js` 冒頭の `https://cdn.jsdelivr.net/...` / `https://storage.googleapis.com/...` の参照を、社内ミラーや `node_modules` からのローカル配信に差し替える必要があります。
- **カメラが複数ある/内蔵カメラを使いたくない場合**: `src/main.js` の `getUserMedia` の `facingMode: "user"` を `deviceId` 指定に変更してください。
- **GPUが無い/古い環境でWebGL初期化に失敗する場合**: `src/handTracking.js` の `delegate: "GPU"` を `"CPU"` に変更すると動きますが、検出は遅くなります。

上記以外は、対応ブラウザとローカルサーバーさえあれば無変更で動作します。
